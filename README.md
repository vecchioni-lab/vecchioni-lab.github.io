# Vecchioni Lab website

The live, ready-to-publish site is in `docs/`. Editable Quarto source files are in the repository root.

## Replace images
Put your own JPG images in `docs/assets/images/` using these names:
- hero.jpg
- crystals.jpg
- metals.jpg
- topology.jpg
- methods.jpg

The placeholders disappear automatically when those files exist.

## GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/docs**.
